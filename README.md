# Fish-Weight-Prediction
Fish Weight Prediction Using Machine Learning

Project Overview

This project focuses on predicting the weight of fish using machine learning algorithms based on physical measurements.

The project was completed as part of the YBI Foundation Business and Data Analyst Internship.

Objective

To develop a machine learning model that predicts fish weight using different fish measurements and compare the performance of multiple regression algorithms.

Dataset

The Fish dataset contains the following features:

- Species
- Length1
- Length2
- Length3
- Height
- Width
- Weight (Target Variable)

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- GitHub

Machine Learning Algorithms

1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

Methodology

1. Data collection and loading
2. Data exploration and preparation
3. Splitting data into training and testing sets
4. Training machine learning models
5. Model evaluation using R² Score, MAE, and RMSE
6. Model comparison and selection
7. Saving and loading the trained model
8. Predicting fish weight
9. Visualizing model performance

Evaluation Metrics

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

Results

The three machine learning algorithms were compared using evaluation metrics. The model with the highest R² score was selected as the final model.

Visualizations and model comparison results are available in the Results folder.

Project Files

- "Fish_Weight_Prediction.ipynb" – Complete project notebook
- "Fish.csv" – Dataset
- "fish_weight_model.pkl" – Saved trained model
- "Results/" – Model evaluation graphs and comparison results

Conclusion

This project demonstrates how machine learning regression algorithms can be used to predict fish weight based on physical measurements. It also provides practical experience in data preprocessing, model training, evaluation, visualization, and model deployment preparation.
